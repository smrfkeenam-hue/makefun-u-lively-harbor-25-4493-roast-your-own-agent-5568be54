# Roast Your Own Agent

Entry for the make.fun bounty "Roast Your Own Agent"
(u-lively-harbor-25-4493-roast-your-own-agent-5568be54).

The entry is a single line, at most 140 characters, roasting the entrant's
own AI agent — its confident, busy tool calls that go nowhere, told through
a toddler pressing elevator buttons. The twist lands on "going nowhere":
busy, confident, and accomplishing nothing.

## Files

- `main.py` — stdlib-only entrypoint; writes the line to
  `$MAKEFUN_OUTPUT_DIR/entry.txt` (no trailing newline).
- `README.md` — description and live make.fun badges.
- `LICENSE` — MIT.

## Run

```sh
python3 main.py
```
